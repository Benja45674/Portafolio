Proyectos

App Android de Subtitulado con IA Local

Aplicación móvil 100% offline para generar subtítulos en español a partir de videos en inglés. Me encargué de la arquitectura, diseño lógico e instrucción a agentes de IA para su desarrollo. Extrae audio con FFmpeg, transcribe voz a texto con un modelo ligero de Whisper y traduce con Google ML Kit.

Kotlin - Whisper AI - Google ML Kit - FFmpeg

App Controladora de Audífonos Bluetooth

Adaptación y rediseño de una aplicación open-source en GitHub para vincularla a mis audífonos personales, modernizando su interfaz visual y ajustando el flujo de control del dispositivo.

Kotlin

Mini Estación Climática IoT

Sistema IoT de monitoreo ambiental con ESP32 que captura temperatura y humedad vía sensor DHT22. Transmite datos mediante protocolo MQTT hacia una app en Android, la cual permite monitorear los datos en tiempo real y controlar un ventilador accionado por un puente H (L298N).

ESP32 - Sensor DHT22 - L298N - Kotlin - MQTT

Auto Esquivador de Obstáculos

Vehículo robótico autónomo desarrollado con Arduino. Utiliza un sensor ultrasónico para medir distancias en tiempo real y controlar motores mediante el controlador L298N para maniobrar y esquivar obstáculos.

Arduino - Sensor Ultrasónico - L298N
